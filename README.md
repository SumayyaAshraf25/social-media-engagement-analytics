
# Social Media Engagement Analytics Using Python

Description: Analyzed social media engagement trends by content type, category, country, age group, and account verification status using Python.

Analysis of 5,000 social media posts: data cleaning, exploration, statistics,
16 visualizations, and insights.

## Contents
- `your_notebook_name.ipynb`: full analysis (Tasks 1-6 and final insights)

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, SciPy

## Key findings
- Differences between post types, categories, countries, age groups, devices
  and sentiments were small and mostly not statistically significant.
- The dataset has no time-of-day data, so day of week was used instead.
